# Terrenvert — site vitrine (démo)

Site vitrine statique pour Terrenvert, entreprise d'architecture paysagère.
HTML / CSS / JavaScript, sans dépendance ni étape de build.

## Lancer en local

```bash
python3 -m http.server 5173
```

Puis ouvrir http://localhost:5173.

## Contenu

- `index.html` — page unique (accueil, services, réalisations, méthode, contact)
- `styles.css` — styles, responsive mobile / tablette / ordinateur
- `script.js` — menu mobile, animations au défilement, formulaire (démo, aucun envoi réel)
- `*.webp` — logo et photos de réalisations

> Démo : le formulaire de devis n'envoie rien pour l'instant.
